API Endpoints

  • POST /register.php - Create account
  • POST /login.php - Login
  • GET /user.php?uid=xxx - User profile
  • GET /transactions.php?uid=xxx - Transactions
  • POST /transactions.php - Create deposit
  • POST /wallet.php - Update wallet
  • POST /admin.php - Approve/Reject
  • POST /send-otp.php - Send OTP
  • POST /verify-otp.php - Verify OTP
